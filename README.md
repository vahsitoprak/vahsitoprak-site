# Vahşi Toprak — GitHub Pages

Bu klasör GitHub Pages için hazırdır. `index.html` kök dizindedir; logo ve mod paketi `assets` klasöründedir.

## Yayınlama

1. GitHub’da `vahsitoprak-site` adında **Public** bir depo oluştur.
2. Depoyu GitHub Desktop ile bilgisayarına klonla.
3. Bu paketi aç. İçindeki `index.html`, `assets`, `.nojekyll` ve `README.md` dosyalarını klonladığın depo klasörünün içine kopyala. `vahsi-toprak` adlı üst klasörü ayrıca kopyalama.
4. GitHub Desktop’ta değişiklikleri commit et ve **Push origin**’e bas.
5. GitHub’da deponun **Settings → Pages** bölümüne gir. **Deploy from a branch** seç; branch `main`, klasör `/(root)` olsun ve **Save**’e bas.

Site adresi `https://GITHUB-KULLANICI-ADIN.github.io/vahsitoprak-site/` biçiminde olur.

Mod paketi yaklaşık 48 MB olduğu için GitHub web sayfasından yüklenemez. Dosyaları GitHub Desktop ile gönder.
